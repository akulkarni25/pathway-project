Overview

The Job Resume Website is a full-stack application that provides AI Resume Formatting, AI Elevator
Pitch Analysis, Job Recommendation Engine, Resume Upload, User Authentication, News Feed
Integration, and Automated Testing using Jest + Supertest.

Technology Stack

Frontend: HTML, CSS, JavaScript
Backend: Node.js + Express 
Database: Supabase (PostgreSQL) 
AI Integration: External OpenAI API 
Testing Frameworks: Jest & Supertest 
Other Tools: Multer, RSS-Parser, Mammoth


Installation
1. Clone the repository
2. Install dependencies (node.js, pdf-parse, mammoth, multer)
3. Create a .env file: SUPABASE_URL=your_url SUPABASE_KEY=your_key OPENAI_API_KEY=your_ai_key PORT=3000 TICKETMASTER_API_KEY=your_api_key
4. Start server: node server.js
5. Open browser at: http://localhost:3000

Or access the deployed website at https://pathway-project.onrender.com
